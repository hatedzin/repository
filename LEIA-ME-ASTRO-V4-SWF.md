# SWF compilada do ASTRO V4

Este arquivo contem o menu moderno, previa de skins, rolagem arrastavel, controles de FPS e as modificacoes anteriores. E a mesma SWF do pacote completo V4.

Ela e um carregador do projeto existente. Nao e uma versao independente: continua precisando do backend e do parser em execucao, da URL autenticada fornecida pelo site e dos arquivos PNG servidos pelo projeto local. Abrir este arquivo diretamente no Flash nao substitui esses servicos e perde os parametros de autenticacao.

Para atualizar uma instalacao existente, feche o Flash, copie este arquivo para DisneyClient-Local-Robot-Novo/DisneyClient/public/ChargeurTransformice.swf (renomeando para ChargeurTransformice.swf) e abra novamente pela URL autenticada do site. Se utiliza a pasta atualizacao/, substitua tambem a copia equivalente nela para que uma atualizacao antiga nao restaure outra SWF.
